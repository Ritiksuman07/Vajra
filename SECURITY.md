# Security Policy

## Reporting a Vulnerability

We take the security of Vajra and its users seriously. If you discover a security vulnerability, please report it responsibly.

**DO NOT** open a public GitHub issue for security vulnerabilities.

Instead, please submit a report via one of the following methods:
- **Email**: security@vajra.ai 
- **GitHub Security Advisory**: Use the "Report a Vulnerability" button on our repo's Security tab

Please include:
1. Your contact information
2. Description of the vulnerability
3. Steps to reproduce
4. Potential impact
5. Any suggested fixes (optional)

## Response Process

1. **Initial Response**: Within 48 hours
2. **Acknowledgment**: Within 72 hours (will include severity assessment)
3. **Fix Timeline**: Varies based on severity
   - Critical: Within 24 hours
   - High: Within 7 days
   - Medium/Low: Within 30 days

## Supported Versions

Only the latest released version of Vajra receives security updates.

## Out of Scope

Issues that are not security-related should be reported as regular [issues](https://github.com/Ritiksuman07/Vajra/issues).

## Recognition

We will credit researchers who report verified vulnerabilities in our release notes, at your discretion (we will respect your preference for anonymity if desired).
